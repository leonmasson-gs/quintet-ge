# Quintet

Free-to-play, no-stake, 18+ daily game: five reels, three free spins a day. This is the look prototype: spins are drawn in the browser and there is no age gate, so keep the deployment protected until the server-side build exists.

Static site, no build step, no environment variables.

Vercel settings: Framework Preset **Other**, Root Directory `./`, Build Command and Output Directory empty (if asked for an output directory, use `.`).
